# Create a list of data objects for 'Stan'

When using 'Stan' to estimate a model, data objects must be passed as a
list, where the name each object corresponds to the name of a variable
in the `data` block of the 'Stan' code. `stan_data()` creates the list
of data objects needed to estimate the model, consistent with the `data`
block generated by
[`stan_code()`](https://dcmstan.r-dcm.org/dev/reference/stan_code.md).

## Usage

``` r
stan_data(x, ...)

## S7 method for class <dcmstan::dcm_specification>
stan_data(x, ..., data, missing = NA, identifier = NULL)

## S7 method for class <dcmstan::quantities>
stan_data(x, ..., dcm_spec, data, missing = NA, identifier = NULL)
```

## Arguments

- x:

  An object to create a data list for (e.g., a [model
  specification](https://dcmstan.r-dcm.org/dev/reference/dcm_specify.md)
  or a [generated
  quantities](https://dcmstan.r-dcm.org/dev/reference/generated-quantities.md)
  object).

- ...:

  Additional arguments passed to methods.

- data:

  The response data. A data frame with 1 row per respondent and 1 column
  per item. May optionally include an additional column of respondent
  identifiers. If an identifier is included, this should be specified
  with `identifier`. All cells for the remaining item columns should be
  either 0 (incorrect response) or 1 (correct response).

- missing:

  An expression specifying how missing values in `data` are encoded
  (e.g., `NA`, `"."`, `-99`). The default is `NA`.

- identifier:

  Optional. If present, the quoted name of the column in `data` that
  contains respondent identifiers.

- dcm_spec:

  For [generated
  quantities](https://dcmstan.r-dcm.org/dev/reference/generated-quantities.md)
  objects, the
  [`dcm_specification`](https://dcmstan.r-dcm.org/dev/reference/dcm_specify.md)
  object for the estimated model.

## Value

A list of data objects.

## Methods

`stan_data()` is an S7 generic with methods available for the following
classes:

- [`dcmstan::dcm_specification`](https://dcmstan.r-dcm.org/dev/reference/dcm_specification.md)

- `dcmstan::quantities`

## Examples

``` r
qmatrix <- data.frame(
  att1 = sample(0:1, size = 5, replace = TRUE),
  att2 = sample(0:1, size = 5, replace = TRUE)
)
data <- data.frame(
  item_1 = sample(0:1, size = 20, replace = TRUE),
  item_2 = sample(0:1, size = 20, replace = TRUE),
  item_3 = sample(0:1, size = 20, replace = TRUE),
  item_4 = sample(0:1, size = 20, replace = TRUE),
  item_5 = sample(0:1, size = 20, replace = TRUE)
)

model_spec <- dcm_specify(qmatrix = qmatrix,
                          measurement_model = lcdm(),
                          structural_model = unconstrained())

stan_data(model_spec, data = data)
```
